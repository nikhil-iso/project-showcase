# Nikhil Patel Portfolio

Personal portfolio website for Nikhil Patel, built with React, TanStack Start,
TanStack Router, Vite, Tailwind CSS v4, and deployed on Vercel.

Production site:

```txt
https://www.nikhil-eng.com
```

## What The Site Includes

- Homepage with profile, about, skills, and personal projects
- Team projects page for rocketry, robotics, and hackathon work
- Downloadable CV, resume, and portfolio PDFs
- Project detail slide-over panels with images, videos, captions, and links
- Server-rendered `robots.txt` and `sitemap.xml`
- Vercel Analytics and Speed Insights
- Vercel Blob-hosted project media

## Tech Stack

- React 19
- TanStack Start
- TanStack Router
- TanStack Query
- Vite
- Tailwind CSS v4
- Radix UI / shadcn-style components
- Vercel Nitro preset
- Vercel Blob
- Sharp for local media optimization

## Getting Started

Install dependencies:

```powershell
npm install
```

Start the development server:

```powershell
npm run dev
```

Build for production:

```powershell
npm run build
```

Preview the production build:

```powershell
npm run preview
```

Run linting:

```powershell
npm run lint
```

On Windows PowerShell, use `npm.cmd` if `npm` is blocked:

```powershell
npm.cmd run build
```

## Project Structure

```txt
src/routes/__root.tsx          Root document, metadata, header, errors
src/routes/index.tsx           Homepage and personal projects
src/routes/team.tsx            Team projects page
src/routes/robots[.]txt.ts     Dynamic robots.txt route
src/routes/sitemap[.]xml.ts    Dynamic sitemap.xml route
src/components/SiteHeader.tsx  Fixed navigation and PDF links
src/components/ProjectList.tsx Project list and detail panel
src/components/ui/             shadcn-style UI components
src/lib/media.ts               Vercel Blob media URLs and metadata
src/lib/site.ts                Canonical site URL helpers
src/server.ts                  Server wrapper and canonical redirects
src/start.ts                   TanStack Start middleware
src/styles.css                 Tailwind theme and global styles
scripts/optimize-media.mjs     Media optimization pipeline
scripts/upload-media.mjs       Vercel Blob upload pipeline
```

Generated file:

```txt
src/routeTree.gen.ts
```

Do not edit `src/routeTree.gen.ts` manually. It is generated by TanStack Router.

## Public Assets

Static files live in `public/`:

```txt
public/favicon.ico
public/Nikhil_Patel-Curriculum_Vitae.pdf
public/Nikhil_Patel-Resume_2026.pdf
public/Nikhil_Patel_Projects.pdf
```

The app currently links the CV, resume, and portfolio PDFs from the header.
Large project media is not served from `public/`; it is uploaded to Vercel Blob
and referenced from `src/lib/media.ts`.

## Media Workflow

Original media files are kept locally in:

```txt
media-source/
```

Optimized/upload-ready files are generated into:

```txt
media-dist/
```

Both directories are ignored by Git.

Optimize media:

```powershell
npm run media:optimize
```

Upload optimized media to Vercel Blob:

```powershell
npm run media:upload
```

Blob credentials are expected in `.env.local` or in the shell environment. Do
not commit `.env.local` or any Blob read-write credentials.

## Environment And Secrets

Never commit:

```txt
.env
.env.local
.env.production
.env.development
media-source/
media-dist/
.vercel/
```

The public Blob base URL in `src/lib/media.ts` is not secret. Write credentials
are secret.

## Deployment

The project is configured for Vercel through `vite.config.ts` using the Nitro
`vercel` preset. The canonical origin is defined in:

```txt
src/lib/site.ts
```

Canonical redirects are handled in:

```txt
src/server.ts
```

## Notes

- Keep `src/routes/__root.tsx` as the only root layout.
- Keep `<Outlet />` in the root component; child routes depend on it.
- Prefer updating project data in `src/routes/index.tsx` and
  `src/routes/team.tsx`.
- Prefer adding media through the optimization/upload scripts instead of placing
  large assets in `public/`.
